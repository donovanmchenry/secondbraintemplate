## Conventions

- Use stable IDs so conversations and optional automations can refer to tasks.
- Keep each item outcome-focused. Store lengthy plans with the owning project.
- Add dates and status only when confirmed; mark uncertainty instead of guessing.
- Review the queue periodically and promote only the few current outcomes to
  `NOW.md`.
