# Optional Task Queue

`NOW.md` is the short list of up to three current outcomes. Use a local
`tasks/index.md` only when the owner also needs a longer-lived queue across projects,
services, or areas of responsibility.

To enable it, copy `index.example.md` to `index.md`. The real queue is gitignored
because tasks often reveal personal plans, dates, relationships, or private project
information.

## Boundaries

- Keep `NOW.md` focused on what matters now; do not mirror the entire queue there.
- Write tasks as concrete outcomes with stable IDs.
- Add deadlines, review dates, and external-system references only when confirmed.
- Keep detailed plans and live status in the owning project or connected service.
- Move completed tasks to the completed section without reusing their IDs.
- Never store credentials, private message bodies, or sensitive source material.
